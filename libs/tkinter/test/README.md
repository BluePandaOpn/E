# Tests / ejemplos

Archivo de ejemplo:
- `example_tk.epp`
- `theme.scss`

Uso:
1. Importa la libreria con `import tkinter`
2. Usa el namespace `tk` (`Tk`, `Label`, `Button`, `Entry`)
3. Aplica colores con `tk.bg`, `tk.fg`, `tk.accent`
4. Carga estilo SCSS con `tk.apply_scss(ui, "test/theme.scss")`
5. Ejecuta `mainloop` para abrir la ventana
